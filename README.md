# VITMate 🎓

VITMate is a simple React-based college companion dashboard designed to help students manage their subjects, tasks, and upcoming events in one place.

## Features

* 🏠 Home dashboard with an overview
* 📚 Subjects section with subject progress
* ✅ Tasks section with task management
* 📅 Events section for upcoming college events
* ➕ Add new tasks
* ☑️ Mark tasks as completed
* 🗑️ Remove tasks
* 🔢 Dynamic pending-task count
* 🔄 Single Page Application (SPA) navigation using React Router

## Technologies Used

* HTML
* CSS
* JavaScript
* React
* React Router
* Vite

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/saunavabiswas024-cell/VITMate.git
```

### 2. Open the project folder

```bash
cd VITMate
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The terminal will provide a local URL. Open that URL in your browser to use VITMate.

## Usage

1. Open the Home page to see the dashboard.
2. Use the navigation bar to move between Subjects, Tasks, and Events.
3. Go to Tasks to add a new task.
4. Use the checkbox to mark a task as completed.
5. Use the Remove button to delete a task.
6. The pending-task count updates automatically.
